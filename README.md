# Recruitment & Placement Management System
Python + Flask + MySQL starter project based on the Kiran Academy documents.

## Setup
1. Install: `pip install -r requirements.txt`
2. Create/import the database using `database/database_schema.sql`.
3. Copy `.env.example` to `.env` and enter your MySQL server details.
4. Run `python app.py`, then open `http://127.0.0.1:5000`.

Important: Pydroid 3 does not automatically include a MySQL server. A reachable MySQL server is required; localhost works only if a server is running on the same device. A remote server or computer-hosted MySQL can be used.

This is a runnable starter, not a finished enterprise system. See `docs/IMPLEMENTATION_NOTES.md` for modules still to complete.
